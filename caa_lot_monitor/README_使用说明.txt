中拍捡漏监控器
================

定位：
  这是一个“只监控、只提醒、不自动出价”的本地工具。
  它不会绕过验证码、不会规避平台风控、不会自动下单。

启动：
  1. 双击“启动中拍捡漏监控器.bat”
  2. 在“中拍页面地址”里粘贴拍卖会页面或标的页面地址
  3. 点击“打开浏览器”
  4. 如果页面出现登录、安全提示、验证码，请在打开的浏览器里手动处理
  5. 浏览器里能正常看到拍卖列表或标的后，回到工具点击“扫描一次”或“开始监控”

筛选逻辑：
  - 默认只看“出价次数=0”或“当前价=起拍价”的疑似无人竞拍标的
  - 默认临近结束阈值是 60 秒
  - 最高预算填 0 表示不限
  - 命中的候选项会高亮，并弹窗/声音提醒

使用建议：
  - 建议先打开拍卖会列表页，而不是单个标的页，这样更容易扫描多个候选
  - 如果扫描结果很少或为空，请确认浏览器里是否真的显示了标的列表文字
  - 平台页面结构可能变化，工具采用通用文本识别，结果请以中拍网页显示为准
  - 出价前一定人工核对标的、保证金、佣金、延时规则、交割条件

本地文件：
  - browser_profile/ 保存浏览器登录状态
  - settings.json 保存上次输入的监控参数
  - monitor.log 保存运行日志
